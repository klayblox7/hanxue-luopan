# Hanxue Luopan Design Context

## Visual Register

Product UI inspired by the Anacuna homepage structure and motion language, adapted for a Korean study-abroad decision platform. Do not copy Anacuna assets or identity; use the large-list format, pill navigation, thin line system, and playful floating stickers as a reference.

## Scene

A student scans a bold directory of Korean study-abroad decisions. The homepage should feel like a confident editorial index: huge readable rows, minimal chrome, direct routes into tools, and a few lively stickers that make the page memorable.

## Color Strategy

Use a near-white paper canvas with black text and thin black lines. Keep accent colors close to the reference mood: soft pink, bright green, warm yellow, lavender, peach, mint, and coral. Accents live in pills and floating stickers, not in large decorative backgrounds.

## Typography

Use Microsoft YaHei UI as the primary Chinese UI font with a strong Gothic fallback stack: `Microsoft YaHei UI`, `Microsoft YaHei`, `微软雅黑`, `PingFang SC`, `Noto Sans CJK SC`, `Hiragino Kaku Gothic ProN`, `Yu Gothic`, `Meiryo`, `MS Gothic`, `Malgun Gothic`, `Inter`, system UI, sans-serif.

Home entry titles use very large, heavy Gothic type. Letter spacing stays normal. The font should feel modern and blunt rather than decorative.

## Layout

The homepage is a large horizontal index. Each module is one full-width row separated by a 1px black rule. The row title is the main visual object; supporting text, source badge, and route status sit to the side. The university row links to `/universities`.

## Motion

Use transform-only motion. Floating stickers gently bob at rest and shift on row hover. Respect reduced motion.
